# RelGT (not included)

This folder is left empty on purpose. The official Relational Graph
Transformer (RelGT) implementation comes from another team's repository,
so please download it separately:

```bash
git clone https://github.com/snap-stanford/relgt.git /tmp/relgt
cp -r /tmp/relgt/* relgt-main/
```

Please check the upstream repository's license (MIT) before use. See the
top-level [README](../README.md#third-party-code-not-included) for details.
