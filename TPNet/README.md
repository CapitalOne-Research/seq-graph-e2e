# TPNet (not included)

This folder is left empty on purpose. The temporal-model baselines used here
(TPNet, CAWN, DyGFormer, TGAT, TCL, GraphMixer, NAT) come from another
author's repository, so please download them separately:

```bash
git clone https://github.com/lxd99/TPNet.git /tmp/TPNet
cp -r /tmp/TPNet/* TPNet/
```

Please check the upstream repository's license before use. See the
top-level [README](../README.md#third-party-code-not-included) for details.
